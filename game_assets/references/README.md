# Game Reference Pack — White House & Area 51

חבילת רפרנסים ויזואליים + מפרט מידות, שנועדה להיות קלט ל־image-to-3D
(Meshy / Tripo / Rodin / Trellis וכו') וליצירת נכסים למשחק.

כל התמונות נוצרו ב-Higgsfield (מודל `gpt_image_2_5`) ושודרגו ל-4K.
הקבצים עצמם יושבים בגלריית ה-Higgsfield של החשבון — ראה `manifest.json`
לקישורים הישירים (סביבת הריצה של הסוכן חסמה את ה-CDN, ולכן לא ניתן היה
לשמור את קבצי ה-PNG בתוך הריפו עצמו).

## מבנה

| קובץ | תוכן |
|---|---|
| `manifest.json` | כל 32 התמונות: מזהה, קטגוריה, שם קובץ מוצע, קישור 1K + 4K, והפרומפט המלא |
| `DIMENSIONS.md` | מידות אמיתיות ומידות מומלצות למשחק (Unity/Unreal, יחידה = 1 מטר) |
| `MORE_LOCATIONS.md` | 25 מיקומים נוספים מגניבים להוספה למשחק |

## איך להשתמש בזה עם מודל 3D

1. **חוץ של מבנה** — הזן את ארבע האליבציות (01–04) + המבט מלמעלה (05) יחד
   כ-multi-view. זה מה שנותן לרשת גיאומטריה נכונה, לא תמונה בודדת.
2. **מבטי 3/4 (06, 07)** — לשימוש כ-reference לתאורה ולחומרים, לא לגיאומטריה.
3. **פנים (10–16, 30–32)** — לא לייצר מהם mesh ישירות; הם reference לבנייה
   ידנית/blockout ול-texture painting. מודלים של image-to-3D מתקשים בחדרים.
4. **פרופים בודדים (19, 27, 29)** — אלה כן קלט מצוין ל-image-to-3D ישיר.
5. אחרי הייצור — התאם את הסקייל לפי `DIMENSIONS.md`. אל תסמוך על הסקייל
   שהמודל מחזיר.

## הערה על דיוק

התמונות הן שחזור מבוסס-AI, לא צילומים אמיתיים. הן נכונות בפרופורציות
ובאופי האדריכלי, אבל פרטים קטנים (מספר חלונות מדויק, עיטורים) עשויים לסטות.
למשחק זה בדרך כלל מספיק; אם צריך דיוק ארכיטקטוני מלא — יש להצליב מול
תוכניות ה-HABS של ספריית הקונגרס (public domain).

Area 51 הוא בסיס סגור שאין ממנו צילומים ציבוריים, ולכן כל התמונות שלו הן
פרשנות אמנותית בסגנון "בסיס סודי במדבר נבדה" — וזה ממילא מה שמשחקים
משתמשים בו.
